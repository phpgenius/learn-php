Level 1 · Lesson 5

Variables & string interpolation

Why double quotes and single quotes behave differently, and how to format output without concatenation noise.

<?php
declare(strict_types=1);

$name  = "Ada";
$price = 49.5;
$qty   = 3;

// Double quotes interpolate variables.
// Single quotes stay literal.
$total = $price * $qty;

printf(
    '%s ordered %d licences — total $%.2f' . "\n",
    $name, $qty, $total
);
// Ada ordered 3 licences — total $148.50

Level 5 · Lesson 2

Validating a form the safe way

Never trust $_POST. Validate, collect every error, and only redirect once the input is clean.

<?php
declare(strict_types=1);

$errors = [];
$email  = '';

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $email = trim($_POST['email'] ?? '');

    if ($email === '') {
        $errors[] = 'Email is required.';
    } elseif (!filter_var(
        $email, FILTER_VALIDATE_EMAIL
    )) {
        $errors[] = 'Not a valid email.';
    }

    if (!$errors) {
        header('Location: /thanks.php', true, 303);
        exit;
    }
}

Level 7 · Lesson 8

PDO prepared statements

The single most important habit in PHP. Bind every value, disable emulation, and let the driver escape for you.

<?php
declare(strict_types=1);

$pdo = new PDO(
    'mysql:host=localhost;dbname=shop;charset=utf8mb4',
    getenv('DB_USER'),
    getenv('DB_PASS'),
    [
        PDO::ATTR_ERRMODE          => PDO::ERRMODE_EXCEPTION,
        PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
        PDO::ATTR_EMULATE_PREPARES => false,
    ]
);

$stmt = $pdo->prepare(
    'SELECT id, name, price FROM products
     WHERE category = :cat ORDER BY price LIMIT :limit'
);
$stmt->bindValue(':cat', $_GET['category'] ?? 'books');
$stmt->bindValue(':limit', 20, PDO::PARAM_INT);
$stmt->execute();

foreach ($stmt as $row) {
    echo htmlspecialchars($row['name']), "\n";
}

FAQ

Questions before you start.

Do I need to know HTML and CSS first?
Yes, at a basic level. PHP runs on the server and returns HTML to the browser, so you should be comfortable with HTML elements, forms and a little CSS before starting Level 1. JavaScript helps from Level 5 onward, when you start handling form submissions and AJAX.
Which PHP version does the course use?
All code targets PHP 8.1 or newer and uses declare(strict_types=1). That means union types, named arguments, match expressions, the nullsafe operator and constructor property promotion are available throughout — and nothing in the course relies on removed PHP 5 or 7 behaviour.
Is everything really free?
Yes — all 96 lessons, all four project briefs, every code sample and the newsletter. There is no paid tier, no locked lesson and no account required. Progress tracking is stored in your own browser. The site is funded by voluntary donations, so nothing is gated behind a payment.
Do I have to pay or donate anything?
No. Donations are entirely voluntary and one-off, and the site stays free whether you give or not. There is no subscription to cancel because there is no subscription.
Do I get a certificate?
There is a printable completion certificate you can generate once you have marked the lessons complete. It is free and needs no account. It is a record of your own progress, not an accredited qualification.
How much time should I budget each week?
Most learners finish in ten to twelve weeks at four to six hours per week. The path is sequential, so you can move faster through Levels 1 and 2 if you already write code in another language.
