while Loops

Condition-first looping and the infinite loop you will write once.

Free 5 min read Control Flow

while tests before each iteration. If the condition never becomes false, the script runs until max_execution_time kills it - a blank page and a log entry.

Make sure something inside the body changes the condition. When reading from a stream or a result set, the read itself is the change.

Example

<?php
declare(strict_types=1);

$i = 1;
while ($i <= 5) {
    echo $i, ' ';
    $i++;          // without this: infinite loop
}
echo "\n";

$queue = ['a', 'b', 'c'];
while ($item = array_shift($queue)) {
    echo $item;
}

Try it

<?php
$n = 10;
while ($n > 1) {
    $n = $n % 2 === 0 ? intdiv($n, 2) : 3 * $n + 1;
    echo $n, ' ';
}

Key takeaways

  • Every while needs a visible exit condition.
  • array_shift() in a loop is O(n^2) on large arrays.
  • Prefer foreach when iterating a known collection.
