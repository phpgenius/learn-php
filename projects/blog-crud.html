A Blog with Full CRUD

Posts, categories, pagination and an admin area — the shape of most PHP applications you will be paid to maintain.

Free Levels 3–7 10–14 hours Intermediate
Why this project

CRUD is the job. This project forces you to model data, write every query with prepared statements, and handle the four operations without duplicating code.

The brief

Build a blog with a public reading side and a password-protected admin side. Posts have a title, slug, body, category, published flag and timestamps.

The public side lists published posts with pagination, shows a single post by slug, and filters by category. The admin side lists all posts, creates, edits and deletes them.

Every database interaction goes through PDO with prepared statements. There is no string concatenation of user input anywhere in this project — that is the point of it.

Requirements

  • Schema with posts and categories tables, foreign key on posts.category_id
  • PDO connection with ERRMODE_EXCEPTION and EMULATE_PREPARES =&gt; false
  • Every query prepared — including the LIMIT/OFFSET in pagination
  • Slugs generated from the title and guaranteed unique
  • Pagination with a real COUNT(*) total, not a guess
  • Admin area behind a session check on every request
  • Delete via POST with a CSRF token, never a GET link
  • htmlspecialchars() on every field rendered into HTML

Starter code

A skeleton to build from — not a solution. Read it, then extend it.

<?php
declare(strict_types=1);

$pdo = new PDO(
    'mysql:host=127.0.0.1;dbname=blog;charset=utf8mb4',
    'app',
    'secret',
    [
        PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
        PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
        PDO::ATTR_EMULATE_PREPARES   => false,
    ]
);

// Pagination: the LIMIT and OFFSET are bound, not interpolated.
$perPage = 10;
$page    = max(1, (int)($_GET['page'] ?? 1));
$offset  = ($page - 1) * $perPage;

$total = (int)$pdo->query(
    'SELECT COUNT(*) FROM posts WHERE published = 1'
)->fetchColumn();

$stmt = $pdo->prepare(
    'SELECT p.id, p.title, p.slug, p.excerpt, p.created_at, c.name AS category
       FROM posts p
       JOIN categories c ON c.id = p.category_id
      WHERE p.published = 1
      ORDER BY p.created_at DESC
      LIMIT :limit OFFSET :offset'
);
$stmt->bindValue(':limit',  $perPage, PDO::PARAM_INT);
$stmt->bindValue(':offset', $offset,  PDO::PARAM_INT);
$stmt->execute();
$posts = $stmt->fetchAll();

$pages = (int)ceil($total / $perPage);
?>
<?php foreach ($posts as $post): ?>
  <article>
    <h2>
      <a href="/post.php?slug=<?= urlencode($post['slug']) ?>">
        <?= htmlspecialchars($post['title']) ?>
      </a>
    </h2>
    <p class="meta">
      <?= htmlspecialchars($post['category']) ?> &middot;
      <?= htmlspecialchars(date('j M Y', strtotime($post['created_at']))) ?>
    </p>
    <p><?= htmlspecialchars($post['excerpt']) ?></p>
  </article>
<?php endforeach; ?>

<nav class="pager">
  <?php for ($i = 1; $i <= $pages; $i++): ?>
    <a href="?page=<?= $i ?>"<?= $i === $page ? ' aria-current="page"' : '' ?>><?= $i ?></a>
  <?php endfor; ?>
</nav>

Stretch goals

  • Add a tags table with a many-to-many join table
  • Add soft deletes with a deleted_at column
  • Add a search box using a LIKE query with a bound parameter
  • Add an RSS feed generated from the published posts

Definition of done

  • Request ?page=abc — you get page 1, not a SQL error
  • Request ?page=99999 — an empty list, not a crash
  • Put &#x27; OR 1=1 -- in the search box — it is treated as a literal string
  • Visit the admin URL while signed out — you are redirected, not shown data
  • Delete a post with a GET request — it is refused
