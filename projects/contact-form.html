A Validated Contact Form

The smallest thing that is still a real application: a form that validates, stores, and confirms.

Free Levels 1–5 4–6 hours Beginner
Why this project

Every PHP job starts here. If you cannot take untrusted input and handle it safely, nothing else you build matters.

The brief

Build a single-page contact form that accepts a name, email, subject and message. It must validate on the server, reject bad input with field-level errors, and preserve what the user typed so they do not retype it.

On success, write the submission to a JSON file (no database yet) and show a confirmation. Include a honeypot field and a simple rate limit so the form cannot be trivially spammed.

This project deliberately has no framework. You are building the request/response loop by hand so that when a framework does it for you later, you know what it is doing.

Requirements

  • Server-side validation for every field — never trust the browser's required attribute
  • Email validated with filter_var($email, FILTER_VALIDATE_EMAIL)
  • Errors rendered next to the field that caused them, with the submitted values preserved
  • All output escaped with htmlspecialchars() — including the error messages
  • Submissions appended to storage/messages.json with a file lock
  • Honeypot field that silently rejects bots
  • A per-IP rate limit of 3 submissions per hour
  • POST/redirect/GET so a refresh does not resubmit

Starter code

A skeleton to build from — not a solution. Read it, then extend it.

<?php
declare(strict_types=1);

$errors = [];
$old = ['name' => '', 'email' => '', 'subject' => '', 'message' => ''];

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    // Keep what the user typed so the form can be re-rendered.
    foreach ($old as $k => $_) {
        $old[$k] = trim((string)($_POST[$k] ?? ''));
    }

    if (mb_strlen($old['name']) < 2) {
        $errors['name'] = 'Enter your name.';
    }
    if (!filter_var($old['email'], FILTER_VALIDATE_EMAIL)) {
        $errors['email'] = 'Enter a valid email address.';
    }
    if (mb_strlen($old['message']) < 20) {
        $errors['message'] = 'Tell us a little more (20 characters minimum).';
    }

    // Honeypot: a real user never fills this hidden field.
    if (!empty($_POST['website'])) {
        $errors['form'] = 'Submission rejected.';
    }

    if (!$errors) {
        $record = $old + ['at' => date('c'), 'ip' => $_SERVER['REMOTE_ADDR'] ?? ''];
        $path = __DIR__ . '/storage/messages.json';
        $fh = fopen($path, 'c+');
        flock($fh, LOCK_EX);
        $raw = stream_get_contents($fh) ?: '[]';
        $all = json_decode($raw, true) ?: [];
        $all[] = $record;
        ftruncate($fh, 0);
        rewind($fh);
        fwrite($fh, json_encode($all, JSON_PRETTY_PRINT));
        flock($fh, LOCK_UN);
        fclose($fh);

        header('Location: /thanks.php', true, 303);
        exit;
    }
}
?>
<form method="post" novalidate>
  <label for="name">Name</label>
  <input id="name" name="name" value="<?= htmlspecialchars($old['name']) ?>">
  <?php if (isset($errors['name'])): ?>
    <p class="err"><?= htmlspecialchars($errors['name']) ?></p>
  <?php endif; ?>

  <label for="email">Email</label>
  <input id="email" name="email" type="email" value="<?= htmlspecialchars($old['email']) ?>">
  <?php if (isset($errors['email'])): ?>
    <p class="err"><?= htmlspecialchars($errors['email']) ?></p>
  <?php endif; ?>

  <label for="message">Message</label>
  <textarea id="message" name="message"><?= htmlspecialchars($old['message']) ?></textarea>

  <!-- honeypot: hidden from humans, irresistible to bots -->
  <div style="position:absolute;left:-9999px" aria-hidden="true">
    <input name="website" tabindex="-1" autocomplete="off">
  </div>

  <button type="submit">Send</button>
</form>

Stretch goals

  • Add a CSRF token to the form and verify it on submit
  • Send a confirmation email with mail() and log the result
  • Add a simple admin page that lists submissions behind a password

Definition of done

  • Submit with every field empty — you get four field-level errors, not a blank page
  • Submit &lt;script&gt;alert(1)&lt;/script&gt; as the name — it renders as text, not a script
  • Refresh the thank-you page — no duplicate record is written
  • Fill the honeypot with curl — the submission is rejected
  • Submit 4 times in an hour — the fourth is rate limited
