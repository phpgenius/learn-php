A JSON REST API with Tests

A versioned JSON API with routing, validation, pagination, auth tokens and a test suite that actually runs.

Free Levels 6–8 14–20 hours Advanced
Why this project

This is the project that proves you can build something another team can consume. It is also the one that teaches you why tests are not optional.

The brief

Build a JSON API for a resource of your choice (tasks, notes, products). It must support list, read, create, update and delete, with consistent response envelopes and correct HTTP status codes.

Add token authentication, request validation with structured error responses, pagination and filtering. No framework — a small router and a handful of classes.

Write a test suite that exercises every endpoint against a test database. The suite must run with a single command and must fail loudly when you break something.

Requirements

  • Front controller with a small router — no .htaccess magic required
  • Consistent envelope: {data, meta} on success, {error: {code, message, fields}} on failure
  • Correct status codes: 200, 201, 204, 400, 401, 403, 404, 422, 429
  • Bearer token auth, tokens stored hashed
  • Validation with per-field error messages in a 422 response
  • Pagination with page, per_page and a meta.total count
  • All queries prepared; no ORM required
  • A test suite covering every endpoint, including the failure paths
  • Content-Type: application/json on every response, including errors

Starter code

A skeleton to build from — not a solution. Read it, then extend it.

<?php
declare(strict_types=1);

// ---- A tiny router: method + path pattern -> handler ----
final class Router
{
    private array $routes = [];

    public function add(string $method, string $pattern, callable $handler): void
    {
        $this->routes[] = [$method, $pattern, $handler];
    }

    public function dispatch(string $method, string $path): void
    {
        foreach ($this->routes as [$m, $pattern, $handler]) {
            $regex = '#^' . preg_replace('#\{(\w+)\}#', '(?P<$1>[^/]+)', $pattern) . '$#';
            if ($m === $method && preg_match($regex, $path, $matches)) {
                $params = array_filter($matches, 'is_string', ARRAY_FILTER_USE_KEY);
                $handler($params);
                return;
            }
        }
        self::json(['error' => ['code' => 'not_found', 'message' => 'No such endpoint']], 404);
    }

    public static function json(array $payload, int $status = 200): void
    {
        http_response_code($status);
        header('Content-Type: application/json; charset=utf-8');
        echo json_encode($payload, JSON_UNESCAPED_SLASHES | JSON_UNESCAPED_UNICODE);
        exit;
    }
}

// ---- Validation with per-field errors ----
function validate(array $input, array $rules): array
{
    $errors = [];
    foreach ($rules as $field => $rule) {
        $value = trim((string)($input[$field] ?? ''));
        if (str_contains($rule, 'required') && $value === '') {
            $errors[$field] = 'This field is required.';
        } elseif ($value !== '' && str_contains($rule, 'email')
                  && !filter_var($value, FILTER_VALIDATE_EMAIL)) {
            $errors[$field] = 'Must be a valid email address.';
        } elseif ($value !== '' && preg_match('/max:(\d+)/', $rule, $m)
                  && mb_strlen($value) > (int)$m[1]) {
            $errors[$field] = 'Must be at most ' . $m[1] . ' characters.';
        }
    }
    return $errors;
}

$router = new Router();
$router->add('GET', '/api/v1/tasks', function () use ($pdo) {
    $stmt = $pdo->query('SELECT id, title, done FROM tasks ORDER BY id DESC');
    Router::json(['data' => $stmt->fetchAll(), 'meta' => ['total' => $stmt->rowCount()]]);
});

$router->add('POST', '/api/v1/tasks', function () use ($pdo) {
    $input  = json_decode(file_get_contents('php://input'), true) ?: [];
    $errors = validate($input, ['title' => 'required|max:120']);
    if ($errors) {
        Router::json(['error' => ['code' => 'validation_failed',
                                  'message' => 'The given data was invalid.',
                                  'fields'  => $errors]], 422);
    }
    $stmt = $pdo->prepare('INSERT INTO tasks (title, done) VALUES (?, 0)');
    $stmt->execute([$input['title']]);
    Router::json(['data' => ['id' => (int)$pdo->lastInsertId(),
                             'title' => $input['title'], 'done' => false]], 201);
});

$router->dispatch($_SERVER['REQUEST_METHOD'], parse_url($_SERVER['REQUEST_URI'], PHP_URL_PATH));

Stretch goals

  • Add ETag support and conditional GET
  • Add rate limiting with a 429 and Retry-After header
  • Add OpenAPI documentation generated from the route table
  • Add a CI config that runs the suite on every push

Definition of done

  • GET /api/v1/tasks returns 200 with a data array and meta.total
  • POST with an empty title returns 422 with a fields.title message
  • POST with valid data returns 201 and a Location-style body
  • GET /api/v1/nope returns 404 with the error envelope, not an HTML page
  • A request with no bearer token returns 401
  • The test suite runs green, and fails when you deliberately break one query
